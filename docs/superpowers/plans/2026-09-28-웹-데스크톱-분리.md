# 손글씨 인식기 웹/데스크톱 분리 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기존 PyTorch 손글씨 인식기를 `desktop_version/` 으로 옮기고, 외부 라이브러리 없이 순수 자바스크립트로 추론하는 `web_version/` 을 새로 만들어 GitHub Pages 에 정적 배포한다.

**Architecture:** `export_weights.py` 가 `mnist_cnn.pt` 의 BatchNorm 을 합성곱에 접어 `weights.bin` + `shape.json` 으로 내보낸다. 웹 쪽은 DOM 을 모르는 세 모듈(`tensor.js` / `preprocess.js` / `model.js`)과 DOM 만 아는 `app.js` 로 나뉜다. 정확성은 PyTorch 가 만든 기대값과 대조하는 `verify.html` 로 증명한다.

**Tech Stack:** Python 3.13 + PyTorch 2.14 + PIL 12.3 (데스크톱) / 순수 ES 모듈 자바스크립트, 외부 라이브러리 0개 (웹)

**Spec:** [docs/superpowers/specs/2026-09-28-웹-데스크톱-분리-design.md](../specs/2026-09-28-웹-데스크톱-분리-design.md)

## Global Constraints

- **파일명은 영어(ASCII), 파일 내부의 식별자·주석·문자열은 한글.** JS 도 동일 (`합성곱2차원()`, `무게중심_이동()`).
- **웹 버전에 외부 라이브러리를 추가하지 않는다.** CDN 링크, npm, 번들러 모두 금지. `atob` 같은 브라우저 내장 API 만 쓴다.
- **파이썬은 반드시 `python` 으로 실행한다.** `py` 는 3.14 를 가리키고 PyTorch 가 없다.
- **파이썬 CLI 출력에 비-ASCII 기호(`█` 등)를 쓰지 않는다.** 콘솔이 cp949 라 `UnicodeEncodeError` 로 죽는다. 브라우저 출력에는 써도 된다.
- **`tensor.js` / `preprocess.js` / `model.js` 는 `document` / `window` / `canvas` 를 참조하지 않는다.** DOM 접근은 `app.js`, `test_runner.js`, 두 HTML 의 인라인 스크립트에만 둔다.
- **웹의 모든 경로는 상대경로.** GitHub Pages 에서 저장소 이름이 경로에 끼어들므로 `/js/app.js` 같은 절대경로는 404 가 된다.
- **정규화 상수(`평균`=0.1307, `표준편차`=0.3081)를 웹에 하드코딩하지 않는다.** `model.py` → `shape.json` → `model.js` 로만 흐른다.
- 허용 오차: 전처리 픽셀 최대 1 (0~255 스케일), 로짓 최대 1e-3, 예측 일치율 200/200.
- 커밋 메시지는 한글. 각 태스크 끝에 커밋한다.

## Review Focus

spec 이 함축하지만 본문이 명시하지 않은 입력들이다. 각 줄의 테스트를 해당 코드를 가진 태스크에 넣어 두었다.

1. **빈 캔버스에서 인식 실행** — 획이 하나도 없으면 `preprocess` 의 bbox 가 비고 무게중심 총합이 0 이다. 0으로 가득 찬 28x28 을 반환하고 앱은 결과를 갱신하지 않아야 한다. 예외를 던지거나 `NaN` 을 표시하면 안 된다. → **태스크 6, 8**
2. **점 하나만 찍음 (bbox 가 1x1)** — `비율 = 20 / 1 = 20` 이라 축소가 아니라 **확대** 경로를 탄다. PIL 은 확대 시 `필터배율` 을 1 로 고정하므로 축소와 커널 폭이 다르다. 이 분기를 빼면 점 하나에 크래시하거나 값이 어긋난다. → **태스크 7**
3. **`weights.bin` 이 `shape.json` 과 크기가 맞지 않음** — 학습 후 `export_weights.py` 를 잊으면 생긴다. 조용히 틀린 숫자를 내놓는 대신 적재 단계에서 명확한 오류를 띄워야 한다. → **태스크 5, 9**
4. **포인터를 캔버스 밖에서 뗌** — 캔버스 밖에서 `pointerup` 이 발생하면 `pointerup` 핸들러가 호출되지 않아 선이 계속 따라다닌다. `setPointerCapture` 로 잡아야 한다. → **태스크 9**
5. **`devicePixelRatio` 가 1 이 아닌 디스플레이** — CSS 크기와 캔버스 백버퍼 크기가 어긋나면 `getImageData` 가 280x280 이 아닌 것을 돌려주고 포인터 좌표도 밀린다. 백버퍼를 280x280 으로 고정하고 좌표를 변환해야 한다. → **태스크 9**

```python
"""
파이썬 쪽 내보내기 로직을 검사하는 스크립트.

테스트 프레임워크를 쓰지 않는 저장소라 평범한 스크립트로 만들었다.

실행:
    python self_check.py
"""

import sys
from pathlib import Path

import torch
import torch.nn.functional as F

from export_weights import 배치정규화_접기, 접은_레이어들, 학습된_모델_읽기

현재폴더 = Path(__file__).resolve().parent

실패목록 = []


def 단언(조건: bool, 설명: str):
    """조건이 거짓이면 실패로 기록한다. 예외를 던지지 않고 끝까지 검사한다."""
    if not 조건:
        실패목록.append(설명)
        print(f"  [실패] {설명}")
    else:
        print(f"  [통과] {설명}")


def 검사_배치정규화_접기():
    """접은 합성곱의 출력이 원래 '합성곱 -> 배치정규화' 와 같아야 한다."""
    print("검사: 배치정규화 접기")
    모델 = 학습된_모델_읽기()
    입력 = torch.randn(4, 1, 28, 28)

    with torch.no_grad():
        원래 = 모델.정규화1(모델.합성곱1(입력))
        새가중치, 새편향 = 배치정규화_접기(모델.합성곱1, 모델.정규화1)
        접은결과 = F.conv2d(입력, 새가중치, 새편향, padding=1)

    최대오차 = (원래 - 접은결과).abs().max().item()
    단언(최대오차 < 1e-5, f"합성곱1 접기 최대오차 {최대오차:.2e} < 1e-5")

    with torch.no_grad():
        중간 = F.max_pool2d(F.relu(원래), 2)
        원래2 = 모델.정규화2(모델.합성곱2(중간))
        새가중치2, 새편향2 = 배치정규화_접기(모델.합성곱2, 모델.정규화2)
        접은결과2 = F.conv2d(중간, 새가중치2, 새편향2, padding=1)

    최대오차2 = (원래2 - 접은결과2).abs().max().item()
    단언(최대오차2 < 1e-5, f"합성곱2 접기 최대오차 {최대오차2:.2e} < 1e-5")


def 검사_레이어_목록():
    """내보낼 레이어의 개수, 이름, 원소 수가 설계와 같아야 한다."""
    print("검사: 레이어 목록")
    모델 = 학습된_모델_읽기()
    레이어들 = 접은_레이어들(모델)

    기대이름 = [
        "합성곱1.가중치", "합성곱1.편향",
        "합성곱2.가중치", "합성곱2.편향",
        "전결합1.가중치", "전결합1.편향",
        "전결합2.가중치", "전결합2.편향",
    ]
    단언([이름 for 이름, _ in 레이어들] == 기대이름, "레이어 이름과 순서")

    전체 = sum(텐서.numel() for _, 텐서 in 레이어들)
    단언(전체 == 421642, f"전체 원소 수 {전체} == 421642")


def main():
    검사_배치정규화_접기()
    검사_레이어_목록()

    print()
    if 실패목록:
        print(f"실패 {len(실패목록)} 건")
        sys.exit(1)
    print("모두 통과")


if __name__ == "__main__":
    main()
```

```python
"""
학습된 mnist_cnn.pt 를 웹 버전이 읽을 수 있는 형식으로 내보낸다.

BatchNorm 을 앞 합성곱에 접어 넣으므로, 자바스크립트 쪽에는 BatchNorm 구현이
필요 없다. Dropout 은 추론 시 항등함수라 내보낼 것이 없다.

실행:
    python export_weights.py

만들어지는 파일 (../web_version/weights/):
    weights.bin          float32 리틀엔디언 원시 바이트
    shape.json           레이어 형상과 오프셋, 정규화 상수
    verify_samples.json  검증용 샘플 (export_samples.py 에서 추가)
"""

import json
from datetime import datetime, timedelta, timezone
from pathlib import Path

import numpy as np
import torch

from model import 숫자인식CNN, 평균, 표준편차

현재폴더 = Path(__file__).resolve().parent
가중치파일 = 현재폴더 / "mnist_cnn.pt"
내보낼폴더 = 현재폴더.parent / "web_version" / "weights"

한국시간 = timezone(timedelta(hours=9))


def 배치정규화_접기(합성곱, 정규화):
    """추론용 BatchNorm 을 앞 합성곱의 가중치/편향에 흡수시킨다.

    배율 = 감마 / sqrt(이동분산 + 엡실론)
    새 가중치 = 원래 가중치 * 배율
    새 편향   = (원래 편향 - 이동평균) * 배율 + 베타
    """

    with torch.no_grad():
        감마 = 정규화.weight
        베타 = 정규화.bias
        이동평균 = 정규화.running_mean
        이동분산 = 정규화.running_var

        배율 = 감마 / torch.sqrt(이동분산 + 정규화.eps)

        새가중치 = 합성곱.weight * 배율.reshape(-1, 1, 1, 1)
        원래편향 = (합성곱.bias if 합성곱.bias is not None
                  else torch.zeros_like(이동평균))
        새편향 = (원래편향 - 이동평균) * 배율 + 베타

    return 새가중치.clone(), 새편향.clone()


def 접은_레이어들(모델: 숫자인식CNN):
    """내보낼 (이름, 텐서) 목록을 순서대로 반환한다.

    이 순서가 weights.bin 의 바이트 순서이자 shape.json 의 기재 순서다.
    여기가 단일 출처이므로 순서를 바꾸면 양쪽이 함께 바뀐다.
    """

    가중치1, 편향1 = 배치정규화_접기(모델.합성곱1, 모델.정규화1)
    가중치2, 편향2 = 배치정규화_접기(모델.합성곱2, 모델.정규화2)

    with torch.no_grad():
        return [
            ("합성곱1.가중치", 가중치1),
            ("합성곱1.편향", 편향1),
            ("합성곱2.가중치", 가중치2),
            ("합성곱2.편향", 편향2),
            ("전결합1.가중치", 모델.전결합1.weight.clone()),
            ("전결합1.편향", 모델.전결합1.bias.clone()),
            ("전결합2.가중치", 모델.전결합2.weight.clone()),
            ("전결합2.편향", 모델.전결합2.bias.clone()),
        ]


def 내보내기(모델: 숫자인식CNN):

def 학습된_모델_읽기() -> 숫자인식CNN:
```

```python
def 캔버스처럼_만들기(원본: Image.Image) -> Image.Image:
    """MNIST 28x28 을 흰 배경 280x280 으로 바꿔 캔버스 입력을 흉내 낸다.

    10배 확대에 최근접 이웃을 쓰는 것이 중요하다. 정수배 최근접은 10x10 블록

def 시험무늬_만들기(크기: int = 37) -> Image.Image:
    """축소 단계만 따로 대조하기 위한 고정 무늬를 만든다.

    가로 그라데이션 + 대각선 + 격자를 섞어, 저주파와 고주파가 모두 들어가게 했다.
    난수를 쓰지 않으므로 몇 번을 돌려도 같은 무늬가 나온다.
    """

    화소 = np.zeros((크기, 크기), dtype=np.uint8)
    for y in range(크기):
        for x in range(크기):
            값 = (x * 255) // (크기 - 1)          # 가로 그라데이션
            if abs(x - y) <= 1:
                값 = 255                          # 대각선
            elif (x // 3 + y // 3) % 2 == 0:
                값 = max(0, 값 - 90)              # 격자
            화소[y, x] = 값
    return Image.fromarray(화소, mode="L")
```

```js
// 단위 테스트를 브라우저에서 돌리기 위한 최소 하네스.
// 저장소에 테스트 프레임워크가 없고 Node 도 설치되어 있지 않아 직접 만들었다.
// 이 파일과 test.html 만 DOM 을 쓴다.

const 결과들 = [];

export function 검사(이름, 본문) {
  try {
    본문();
    결과들.push({ 이름, 통과: true, 메시지: "" });
  } catch (오류) {
    결과들.push({ 이름, 통과: false, 메시지: 오류.message });
  }
}

export function 같아야(실제, 기대, 설명 = "") {
  if (실제 !== 기대) {
    throw new Error(`${설명} 기대 ${기대}, 실제 ${실제}`);
  }
}

export function 가까워야(실제, 기대, 허용, 설명 = "") {
  if (!(Math.abs(실제 - 기대) <= 허용)) {
    throw new Error(`${설명} 기대 ${기대} (허용 ${허용}), 실제 ${실제}`);
  }
}

export function 배열이_가까워야(실제, 기대, 허용, 설명 = "") {
  if (실제.length !== 기대.length) {
    throw new Error(`${설명} 길이 기대 ${기대.length}, 실제 ${실제.length}`);
  }
  for (let i = 0; i < 기대.length; i++) {
    if (!(Math.abs(실제[i] - 기대[i]) <= 허용)) {
      throw new Error(
        `${설명} [${i}] 기대 ${기대[i]} (허용 ${허용}), 실제 ${실제[i]}`
      );
    }
  }
}

export function 결과보고(대상요소) {
  const 실패 = 결과들.filter((항목) => !항목.통과);
  const 줄들 = 결과들.map(
    (항목) => `${항목.통과 ? "통과" : "실패"}  ${항목.이름}` +
              (항목.통과 ? "" : `\n        ${항목.메시지}`)
  );
  const 요약 = `\n${결과들.length - 실패.length}/${결과들.length} 통과` +
               (실패.length ? `\n\n판정: 실패` : `\n\n판정: 통과`);
  const 본문 = 줄들.join("\n") + 요약;

  대상요소.textContent = 본문;
  console.log(본문);
  // 브라우저 도구가 한 줄로 판정을 읽을 수 있게 한다
  console.log(실패.length ? "판정=실패" : "판정=통과");
}
```

```js
// CNN 추론에 필요한 최소한의 수치 연산.
//
// 텐서 클래스를 만들지 않고 평평한 Float32Array 와 명시적인 차원 인자를 쓴다.
// 연산이 다섯 개뿐이라 추상화 비용이 이득보다 크다.
//
// 모든 배열은 채널 우선 배치다: 인덱스 = 채널 * 크기 * 크기 + y * 크기 + x.
// 이 순서는 PyTorch 의 메모리 배치와 같아야 한다. 어긋나면 전결합1 이
// 엉뚱한 값을 받는다.
//
// 이 파일은 DOM 을 참조하지 않는다 (verify.html 이 그대로 쓰기 때문).

/**
 * 3x3 커널, padding 1, stride 1 고정 합성곱.
 *
 * 모델이 이 설정만 쓰므로 일반화하지 않았다. 커널 크기가 고정이라
 * 안쪽 루프가 단순해지는 이점도 있다.
 *
 * 가중치 배치는 PyTorch Conv2d 와 같은 (출력채널, 입력채널, 3, 3) 이다.
 */
export function 합성곱2차원(입력, 입력채널수, 크기, 가중치, 편향, 출력채널수) {
  const 면적 = 크기 * 크기;
  const 출력 = new Float32Array(출력채널수 * 면적);

  for (let 출채널 = 0; 출채널 < 출력채널수; 출채널 += 1) {
    const 커널기준 = 출채널 * 입력채널수 * 9;
    const 출기준 = 출채널 * 면적;

    for (let y = 0; y < 크기; y += 1) {
      for (let x = 0; x < 크기; x += 1) {
        let 합 = 편향[출채널];

        for (let 입채널 = 0; 입채널 < 입력채널수; 입채널 += 1) {
          const 입기준 = 입채널 * 면적;
          const 커널 = 커널기준 + 입채널 * 9;

          for (let dy = -1; dy <= 1; dy += 1) {
            const 표본y = y + dy;
            if (표본y < 0 || 표본y >= 크기) continue;   // padding 은 0

            for (let dx = -1; dx <= 1; dx += 1) {
              const 표본x = x + dx;
              if (표본x < 0 || 표본x >= 크기) continue;

              합 += 입력[입기준 + 표본y * 크기 + 표본x] *
                    가중치[커널 + (dy + 1) * 3 + (dx + 1)];
            }
          }
        }

        출력[출기준 + y * 크기 + x] = 합;
      }
    }
  }

  return 출력;
}

/** 음수를 0 으로 바꾼다. 제자리 연산 후 같은 배열을 반환한다. */
export function 렐루(배열) {
  for (let i = 0; i < 배열.length; i += 1) {
    if (배열[i] < 0) 배열[i] = 0;
  }
  return 배열;
}

/** 2x2, stride 2 최대 풀링. 크기는 짝수여야 한다. */
export function 최대풀링2차원(입력, 채널수, 크기) {
  const 새크기 = 크기 >> 1;
  const 출력 = new Float32Array(채널수 * 새크기 * 새크기);

  for (let 채널 = 0; 채널 < 채널수; 채널 += 1) {
    const 입기준 = 채널 * 크기 * 크기;
    const 출기준 = 채널 * 새크기 * 새크기;

    for (let y = 0; y < 새크기; y += 1) {
      for (let x = 0; x < 새크기; x += 1) {
        const 왼위 = 입기준 + (y * 2) * 크기 + x * 2;
        const 최댓값 = Math.max(
          입력[왼위],
          입력[왼위 + 1],
          입력[왼위 + 크기],
          입력[왼위 + 크기 + 1],
        );
        출력[출기준 + y * 새크기 + x] = 최댓값;
      }
    }
  }

  return 출력;
}

/** 가중치 배치는 PyTorch Linear 와 같은 (출력특징, 입력특징) 이다. */
export function 전결합(입력, 가중치, 편향, 입력수, 출력수) {
  const 출력 = new Float32Array(출력수);

  for (let 출 = 0; 출 < 출력수; 출 += 1) {
    const 기준 = 출 * 입력수;
    let 합 = 편향[출];
    for (let 입 = 0; 입 < 입력수; 입 += 1) {
      합 += 입력[입] * 가중치[기준 + 입];
    }
    출력[출] = 합;
  }

  return 출력;
}

/**
 * PyTorch 의 log_softmax 와 같은 수식.
 *
 * 최댓값을 빼서 exp 가 넘치는 것을 막는다. PyTorch 도 같은 방식이라야
 * 로짓을 자릿수까지 대조할 수 있다.
 */
export function 로그소프트맥스(배열) {
  let 최댓값 = -Infinity;
  for (const 값 of 배열) {
    if (값 > 최댓값) 최댓값 = 값;
  }

  let 지수합 = 0;
  for (const 값 of 배열) {
    지수합 += Math.exp(값 - 최댓값);
  }
  const 로그합 = Math.log(지수합);

  const 출력 = new Float32Array(배열.length);
  for (let i = 0; i < 배열.length; i += 1) {
    출력[i] = 배열[i] - 최댓값 - 로그합;
  }
  return 출력;
}
```

```js
// 내보낸 가중치를 읽어 순전파를 수행한다.
//
// BatchNorm 과 Dropout 은 export_weights.py 가 접어 넣었거나(BatchNorm)
// 추론 시 항등함수라(Dropout) 여기에 없다. model.py 의 forward 와 층 순서가
// 같아야 한다.
//
// 이 파일은 DOM 을 참조하지 않는다.

import {
  합성곱2차원, 렐루, 최대풀링2차원, 전결합, 로그소프트맥스,
} from "./tensor.js";

/**
 * shape.json 과 weights.bin 을 읽어 레이어별 Float32Array 로 나눈다.
 *
 * 기준경로는 반드시 상대경로여야 한다. GitHub Pages 에서는 저장소 이름이
 * 경로 앞에 붙기 때문에 절대경로를 쓰면 404 가 난다.
 */
export async function 가중치_불러오기(기준경로 = "./weights/") {
  const 구조응답 = await fetch(`${기준경로}shape.json`);
  if (!구조응답.ok) {
    throw new Error(
      `shape.json 을 읽지 못했습니다 (${구조응답.status}). ` +
      `desktop_version 에서 'python export_weights.py' 를 실행했는지 확인하세요.`
    );
  }
  const 구조 = await 구조응답.json();

  const 바이트응답 = await fetch(`${기준경로}weights.bin`);
  if (!바이트응답.ok) {
    throw new Error(
      `weights.bin 을 읽지 못했습니다 (${바이트응답.status}). ` +
      `desktop_version 에서 'python export_weights.py' 를 실행했는지 확인하세요.`
    );
  }
  const 버퍼 = await 바이트응답.arrayBuffer();

  // 낡은 내보내기를 조용히 쓰는 것을 막는다. 크기가 어긋나면 여기서 멈춘다.
  const 기대바이트 = 구조.전체원소수 * 4;
  if (버퍼.byteLength !== 기대바이트) {
    throw new Error(
      `weights.bin 크기가 shape.json 과 다릅니다 ` +
      `(기대 ${기대바이트} 바이트, 실제 ${버퍼.byteLength} 바이트). ` +
      `export_weights.py 를 다시 실행하세요.`
    );
  }

  const 레이어 = {};
  for (const 항목 of 구조.레이어들) {
    레이어[항목.이름] = new Float32Array(버퍼, 항목.오프셋 * 4, 항목.원소수);
  }

  return {
    정규화: 구조.정규화,
    레이어,
    생성일시: 구조.생성일시,
  };
}

/**
 * 28x28 입력(0~255)을 받아 로그 확률 10개를 반환한다.
 *
 * model.py 의 forward 와 같은 순서:
 *   합성곱1 -> 렐루 -> 풀링 -> 합성곱2 -> 렐루 -> 풀링
 *   -> 평탄화 -> 전결합1 -> 렐루 -> 전결합2 -> 로그소프트맥스
 */
export function 순전파(가중치묶음, 입력28x28) {
  const { 평균, 표준편차 } = 가중치묶음.정규화;
  const 층 = 가중치묶음.레이어;

  // 정규화 상수는 shape.json 에서 온다. 여기에 숫자를 적지 않는다.
  const 정규화됨 = new Float32Array(784);
  for (let i = 0; i < 784; i += 1) {
    정규화됨[i] = (입력28x28[i] / 255 - 평균) / 표준편차;
  }

  let 특징 = 합성곱2차원(정규화됨, 1, 28, 층["합성곱1.가중치"], 층["합성곱1.편향"], 32);
  특징 = 최대풀링2차원(렐루(특징), 32, 28);           // 28x28 -> 14x14

  특징 = 합성곱2차원(특징, 32, 14, 층["합성곱2.가중치"], 층["합성곱2.편향"], 64);
  특징 = 최대풀링2차원(렐루(특징), 64, 14);           // 14x14 -> 7x7

  // 평탄화: PyTorch 의 x.flatten(1) 과 같은 채널 우선 순서(채널*49 + y*7 + x).
  // 특징 배열이 이미 그 순서라 재배치가 필요 없다.
  let 값 = 전결합(특징, 층["전결합1.가중치"], 층["전결합1.편향"], 3136, 128);
  값 = 전결합(렐루(값), 층["전결합2.가중치"], 층["전결합2.편향"], 128, 10);

  return 로그소프트맥스(값);
}

/** 로그 확률에서 확률이 높은 순으로 상위 후보를 뽑는다. */
export function 상위후보(로그확률, 개수 = 3) {
  const 전체 = [];
  for (let 숫자 = 0; 숫자 < 로그확률.length; 숫자 += 1) {
    전체.push({ 숫자, 확률: Math.exp(로그확률[숫자]) });
  }
  전체.sort((가, 나) => 나.확률 - 가.확률);
  return 전체.slice(0, 개수);
}
```

```js
// 손으로 그린 그림을 MNIST 형식(28x28)으로 바꾸는 전처리.
//
// desktop_version/preprocess.py 를 그대로 옮긴 것이다. 단계 순서와 수치가
// 파이썬과 같아야 두 버전의 인식 결과가 일치한다. "더 올바른" 구현으로
// 고치고 싶어지는 자리가 몇 군데 있는데, 고치면 결과가 갈린다.
//
// 그림 객체 형태: { 너비, 높이, 화소 } — 화소는 Uint8ClampedArray, 행 우선.
// 이 파일은 DOM 을 참조하지 않는다.

/** 그림 객체를 만든다. 화소를 주지 않으면 0 으로 채운다. */
export function 그림만들기(너비, 높이, 화소 = null) {
  return {
    너비,
    높이,
    화소: 화소 ?? new Uint8ClampedArray(너비 * 높이),
  };
}

/**
 * 파이썬 round() 와 같은 짝수 반올림.
 *
 * JS 의 Math.round() 는 .5 에서 항상 큰 쪽으로 붙지만 파이썬은 짝수 쪽으로
 * 붙는다. 긴 변 20px 축소에서 1픽셀이 어긋나면 이후 모든 픽셀이 밀린다.
 */
export function 파이썬_반올림(값) {
  const 내림 = Math.floor(값);
  const 나머지 = 값 - 내림;
  if (나머지 > 0.5) return 내림 + 1;
  if (나머지 < 0.5) return 내림;
  return 내림 % 2 === 0 ? 내림 : 내림 + 1;
}

/**
 * RGBA 바이트 배열을 회색조 그림으로 바꾼다.
 *
 * PIL 의 convert("L") 과 같은 고정소수점 식을 쓴다.
 * 19595 + 38470 + 7471 = 65536 이므로 R=G=B 인 입력은 그 값이 그대로 나온다.
 * 캔버스는 흰 선만 그리므로 실제로는 항상 그 경우다.
 */
export function 회색조로(너비, 높이, RGBA바이트) {
  const 화소 = new Uint8ClampedArray(너비 * 높이);
  for (let i = 0; i < 화소.length; i += 1) {
    const 기준 = i * 4;
    화소[i] = (RGBA바이트[기준] * 19595 +
               RGBA바이트[기준 + 1] * 38470 +
               RGBA바이트[기준 + 2] * 7471 + 0x8000) >> 16;
  }
  return 그림만들기(너비, 높이, 화소);
}

/**
 * MNIST 는 검은 배경에 흰 글씨다. 배경이 밝으면 뒤집는다.
 *
 * 가장자리 표본을 모으는 방식이 preprocess.py 와 같아야 한다. 파이썬은
 * np.concatenate([첫행, 끝행, 첫열, 끝열]) 로 모으는데 네 모서리가 두 번씩
 * 들어간다. 이 중복을 일부러 그대로 재현한다 — 고치면 경계 사례에서 반전
 * 판단이 갈려 결과 전체가 뒤집힌다.
 */
export function 배경이_밝으면_반전(그림) {
  const { 너비, 높이, 화소 } = 그림;
  let 합 = 0;
  let 개수 = 0;

  for (let x = 0; x < 너비; x += 1) {           // 첫 행
    합 += 화소[x]; 개수 += 1;
  }
  for (let x = 0; x < 너비; x += 1) {           // 끝 행
    합 += 화소[(높이 - 1) * 너비 + x]; 개수 += 1;
  }
  for (let y = 0; y < 높이; y += 1) {           // 첫 열
    합 += 화소[y * 너비]; 개수 += 1;
  }
  for (let y = 0; y < 높이; y += 1) {           // 끝 열
    합 += 화소[y * 너비 + (너비 - 1)]; 개수 += 1;
  }

  if (합 / 개수 <= 127) return 그림;

  const 반전된 = new Uint8ClampedArray(화소.length);
  for (let i = 0; i < 화소.length; i += 1) 반전된[i] = 255 - 화소[i];
  return 그림만들기(너비, 높이, 반전된);
}

/**
 * 밝기 30 초과인 화소의 최소 사각형만 남긴다.
 * 글씨가 없으면 null 을 반환한다.
 */
export function 글씨영역_자르기(그림) {
  const { 너비, 높이, 화소 } = 그림;
  let 위 = 높이, 왼쪽 = 너비, 아래 = -1, 오른쪽 = -1;

  for (let y = 0; y < 높이; y += 1) {
    for (let x = 0; x < 너비; x += 1) {
      if (화소[y * 너비 + x] > 30) {
        if (y < 위) 위 = y;
        if (y > 아래) 아래 = y;
        if (x < 왼쪽) 왼쪽 = x;
        if (x > 오른쪽) 오른쪽 = x;
      }
    }
  }

  if (아래 < 0) return null;

  const 새너비 = 오른쪽 - 왼쪽 + 1;
  const 새높이 = 아래 - 위 + 1;
  const 잘린화소 = new Uint8ClampedArray(새너비 * 새높이);
  for (let y = 0; y < 새높이; y += 1) {
    for (let x = 0; x < 새너비; x += 1) {
      잘린화소[y * 새너비 + x] = 화소[(위 + y) * 너비 + (왼쪽 + x)];
    }
  }
  return 그림만들기(새너비, 새높이, 잘린화소);
}

/**
 * 글씨의 무게중심을 28x28 의 정중앙(13.5, 13.5)으로 옮긴다.
 *
 * 이 단계를 빼면 눈에 띄게 틀린다. MNIST 가 이렇게 정렬된 데이터이기 때문이다.
 * PIL 의 AFFINE 변환은 출력 좌표에서 입력 좌표를 역산하므로
 * 출력(x, y) = 입력(x - 이동x, y - 이동y) 가 된다. 정수 이동이라 보간이 없다.
 */
export function 무게중심_이동(그림) {
  const { 너비, 높이, 화소 } = 그림;
  let 총합 = 0;
  let 가중x = 0;
  let 가중y = 0;

  for (let y = 0; y < 높이; y += 1) {
    for (let x = 0; x < 너비; x += 1) {
      const 값 = 화소[y * 너비 + x];
      총합 += 값;
      가중x += x * 값;
      가중y += y * 값;
    }
  }

  if (총합 === 0) return 그림;          // 빈 그림이면 그대로 둔다

  const 이동x = 파이썬_반올림(13.5 - 가중x / 총합);
  const 이동y = 파이썬_반올림(13.5 - 가중y / 총합);
  if (이동x === 0 && 이동y === 0) return 그림;

  const 옮긴화소 = new Uint8ClampedArray(너비 * 높이);
  for (let y = 0; y < 높이; y += 1) {
    const 원본y = y - 이동y;
    if (원본y < 0 || 원본y >= 높이) continue;
    for (let x = 0; x < 너비; x += 1) {
      const 원본x = x - 이동x;
      if (원본x < 0 || 원본x >= 너비) continue;
      옮긴화소[y * 너비 + x] = 화소[원본y * 너비 + 원본x];
    }
  }
  return 그림만들기(너비, 높이, 옮긴화소);
}

/** 태스크 7 에서 구현한다. */
export function 란초스_크기변경(그림, 새너비, 새높이) {
  throw new Error("란초스_크기변경 미구현");
}

/**
 * 임의 크기 손글씨 그림을 28x28 MNIST 규격으로 바꾼다.
 *
 * preprocess.py 의 MNIST형식으로_변환 과 같은 순서다.
 */
export function MNIST형식으로_변환(그림) {
  const 회색 = 배경이_밝으면_반전(그림);
  const 잘린 = 글씨영역_자르기(회색);

  // 아무것도 그리지 않은 경우: 빈 검은 이미지를 반환한다
  if (잘린 === null) return 그림만들기(28, 28);

  // 가로세로 비율을 유지한 채 긴 변이 20픽셀이 되도록 바꾼다
  const 비율 = 20.0 / Math.max(잘린.너비, 잘린.높이);
  const 새너비 = Math.max(1, 파이썬_반올림(잘린.너비 * 비율));
  const 새높이 = Math.max(1, 파이썬_반올림(잘린.높이 * 비율));
  const 축소 = 란초스_크기변경(잘린, 새너비, 새높이);

  // 28x28 검은 캔버스 중앙에 붙인다
  const 결과 = 그림만들기(28, 28);
  const 시작x = (28 - 새너비) >> 1;
  const 시작y = (28 - 새높이) >> 1;
  for (let y = 0; y < 새높이; y += 1) {
    for (let x = 0; x < 새너비; x += 1) {
      결과.화소[(시작y + y) * 28 + (시작x + x)] = 축소.화소[y * 새너비 + x];
    }
  }

  return 무게중심_이동(결과);
}
```

PIL 의 `ImagingResample` 을 그대로 따른다. **부동소수점으로 근사하지 않고 22비트 고정소수점을 재현한다.** PIL 이 uint8 이미지에 그 경로를 쓰기 때문이며, 그래야 오차가 0 이 된다.

주의할 점 세 가지:
- JS 의 `>>` 는 32비트 연산이다. 누산값이 `255 × 2^22 ≈ 1.07e9` 를 넘으므로 `>>` 를 쓰면 부호가 뒤집힌다. `Math.floor(합 / 2**22)` 를 쓴다 (C 의 산술 우시프트와 같다).
- 계수를 정규화한 **뒤에** 고정소수점으로 바꾼다.
- 해당 축의 크기가 그대로면 그 패스를 건너뛴다. PIL 이 그렇게 한다.

```js
// PIL 의 고정소수점 리샘플링이 쓰는 비트 수 (Resample.c 의 PRECISION_BITS).
const 정밀도비트 = 22;
const 정밀도배수 = 2 ** 정밀도비트;

/** Lanczos3 커널. sinc(x) * sinc(x/3), 지지구간 3.0. */
function 란초스커널(값) {
  if (값 <= -3.0 || 값 >= 3.0) return 0.0;
  if (값 === 0.0) return 1.0;
  const 파이값 = Math.PI * 값;
  return (Math.sin(파이값) / 파이값) * (Math.sin(파이값 / 3) / (파이값 / 3));
}

/**
 * 한 축의 리샘플링 계수를 미리 계산한다.
 *
 * PIL 의 precompute_coeffs 와 같다. 축소할 때 커널을 늘리는 것(필터배율)이
 * 에일리어싱을 막는 핵심이라 빼면 안 된다. 확대할 때는 1 로 고정된다.
 */
function 계수_준비(입력크기, 출력크기) {
  const 배율 = 입력크기 / 출력크기;
  const 필터배율 = Math.max(1.0, 배율);
  const 지지구간 = 3.0 * 필터배율;

  const 폭 = Math.ceil(지지구간) * 2 + 1;
  const 계수 = new Int32Array(출력크기 * 폭);
  const 시작 = new Int32Array(출력크기);
  const 길이 = new Int32Array(출력크기);

  for (let 출 = 0; 출 < 출력크기; 출 += 1) {
    const 중심 = (출 + 0.5) * 배율;
    let 처음 = Math.floor(중심 - 지지구간);
    if (처음 < 0) 처음 = 0;
    let 끝 = Math.ceil(중심 + 지지구간);
    if (끝 > 입력크기) 끝 = 입력크기;

    const 개수 = 끝 - 처음;
    시작[출] = 처음;
    길이[출] = 개수;

    const 임시 = new Float64Array(개수);
    let 합 = 0.0;
    for (let i = 0; i < 개수; i += 1) {
      const 무게 = 란초스커널((처음 + i - 중심 + 0.5) / 필터배율);
      임시[i] = 무게;
      합 += 무게;
    }

    // 계수를 정규화한 뒤에 고정소수점으로 바꾼다. 순서를 바꾸면 값이 달라진다.
    for (let i = 0; i < 개수; i += 1) {
      const 정규화된 = 합 !== 0.0 ? 임시[i] / 합 : 0.0;
      const 확대 = 정규화된 * 정밀도배수;
      계수[출 * 폭 + i] = Math.trunc(확대 >= 0 ? 확대 + 0.5 : 확대 - 0.5);
    }
  }

  return { 계수, 시작, 길이, 폭 };
}

function 클램프8(값) {
  if (값 < 0) return 0;
  if (값 > 255) return 255;
  return 값;
}

/**
 * PIL 의 LANCZOS 축소/확대를 재현한다.
 *
 * 가로 패스 -> 세로 패스 순서와 패스 사이의 8비트 반올림까지 PIL 과 같다.
 * canvas.drawImage 로 대체하면 안 된다 — 브라우저마다 보간이 다르고
 * 명세에도 고정되어 있지 않아 재현성이 없다.
 */
export function 란초스_크기변경(그림, 새너비, 새높이) {
  let 현재 = 그림;

  if (현재.너비 !== 새너비) {
    현재 = 한축_리샘플(현재, 새너비, 현재.높이, true);
  }
  if (현재.높이 !== 새높이) {
    현재 = 한축_리샘플(현재, 현재.너비, 새높이, false);
  }

  // 두 축 모두 그대로면 원본을 복사해 돌려준다 (호출자가 고치지 못하도록)
  if (현재 === 그림) {
    return 그림만들기(그림.너비, 그림.높이, 그림.화소.slice());
  }
  return 현재;
}

function 한축_리샘플(그림, 새너비, 새높이, 가로인가) {
  const { 너비, 높이, 화소 } = 그림;
  const 출력화소 = new Uint8ClampedArray(새너비 * 새높이);
  const 반올림 = 1 << (정밀도비트 - 1);

  if (가로인가) {
    const { 계수, 시작, 길이, 폭 } = 계수_준비(너비, 새너비);
    for (let y = 0; y < 새높이; y += 1) {
      for (let x = 0; x < 새너비; x += 1) {
        let 합 = 반올림;
        const 기준 = x * 폭;
        for (let i = 0; i < 길이[x]; i += 1) {
          합 += 화소[y * 너비 + (시작[x] + i)] * 계수[기준 + i];
        }
        // JS 의 >> 는 32비트라 여기서 넘친다. 나눗셈 + floor 를 쓴다.
        출력화소[y * 새너비 + x] = 클램프8(Math.floor(합 / 정밀도배수));
      }
    }
  } else {
    const { 계수, 시작, 길이, 폭 } = 계수_준비(높이, 새높이);
    for (let y = 0; y < 새높이; y += 1) {
      const 기준 = y * 폭;
      for (let x = 0; x < 새너비; x += 1) {
        let 합 = 반올림;
        for (let i = 0; i < 길이[y]; i += 1) {
          합 += 화소[(시작[y] + i) * 너비 + x] * 계수[기준 + i];
        }
        출력화소[y * 새너비 + x] = 클램프8(Math.floor(합 / 정밀도배수));
      }
    }
  }

  return 그림만들기(새너비, 새높이, 출력화소);
}
```

```js
function 캔버스좌표(사건) {
  const 영역 = 캔버스.getBoundingClientRect();
  return {
    x: (사건.clientX - 영역.left) * (캔버스크기 / 영역.width),
    y: (사건.clientY - 영역.top) * (캔버스크기 / 영역.height),
  };
}

function 붓_설정() {
  그리기.lineWidth = 붓굵기;
  그리기.lineCap = "round";
  그리기.lineJoin = "round";
  그리기.strokeStyle = "#ffffff";
  그리기.fillStyle = "#ffffff";
}

function 캔버스_비우기() {
  그리기.fillStyle = "#000000";
  그리기.fillRect(0, 0, 캔버스크기, 캔버스크기);
  붓_설정();
}

function 누름(사건) {
  if (!가중치묶음) return;
  그리는중 = true;
  이전좌표 = 캔버스좌표(사건);

  // 점 하나만 찍어도 보이도록 원을 그린다
  그리기.beginPath();
  그리기.arc(이전좌표.x, 이전좌표.y, 붓굵기 / 2, 0, Math.PI * 2);

  캔버스.setPointerCapture(사건.pointerId);

function 끌기(사건) {
  if (!그리는중) return;
  const 지금 = 캔버스좌표(사건);
  그리기.beginPath();
  그리기.moveTo(이전좌표.x, 이전좌표.y);
  그리기.lineTo(지금.x, 지금.y);
  그리기.stroke();
  이전좌표 = 지금;
}

function 뗌(사건) {
  if (!그리는중) return;
  그리는중 = false;
  이전좌표 = null;
  if (캔버스.hasPointerCapture(사건.pointerId)) {
    캔버스.releasePointerCapture(사건.pointerId);

  확신도.textContent = "숫자를 그려 주세요";

function 인식하기() {
  if (!가중치묶음) return;

  const 원본 = 그리기.getImageData(0, 0, 캔버스크기, 캔버스크기);
  const 회색 = 회색조로(캔버스크기, 캔버스크기, 원본.data);
  const 정리된 = MNIST형식으로_변환(회색);

  let 총합 = 0;
  for (const 값 of 정리된.화소) 총합 += 값;
  if (총합 === 0) return;

  const 로그확률 = 순전파(가중치묶음, 정리된.화소);
  const 후보 = 상위후보(로그확률, 3);
```

## 전처리에서 건드리면 안 되는 것들

`preprocess.js` 는 `../desktop_version/preprocess.py` 의 포팅입니다.
**"더 올바른" 구현으로 고치면 두 버전의 인식 결과가 갈립니다.**

- **`파이썬_반올림()` 을 `Math.round()` 로 바꾸지 마세요.** 파이썬 `round()` 는
  짝수 반올림이고 JS 는 항상 올림입니다. 긴 변 20px 축소에서 1픽셀이 어긋나면
  이후 모든 픽셀이 밀립니다.
- **`배경이_밝으면_반전()` 의 모서리 중복 계산을 고치지 마세요.** 파이썬이
  `np.concatenate` 로 가장자리를 모으면서 네 모서리를 두 번씩 셉니다. 일부러
  재현한 것입니다.
- **`란초스_크기변경()` 을 `canvas.drawImage` 로 대체하지 마세요.** 브라우저마다
  보간이 다르고 명세에도 고정되어 있지 않아 재현성이 없습니다.
- **`란초스_크기변경()` 안에서 `>>` 를 쓰지 마세요.** JS 의 시프트는 32비트라
  누산값(최대 약 1.07e9)에서 부호가 뒤집힙니다. `Math.floor(합 / 정밀도배수)` 입니다.
- **무게중심 이동 단계를 빼지 마세요.** MNIST 가 무게중심 정렬된 데이터라
  빼면 눈에 띄게 틀립니다.
